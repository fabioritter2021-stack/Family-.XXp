FAMILYXP PWA

Diese Dateien sind für eine installierbare PWA gedacht.
Sie kann auf Android zum Startbildschirm hinzugefügt werden und öffnet sich anschließend im Standalone-Modus.

WICHTIG:
Die PWA benötigt für Service Worker/Installation normalerweise eine HTTPS-Adresse (oder localhost).
Wenn die Dateien nur als file:// geöffnet werden, funktioniert die Installation möglicherweise nicht.

Schnellster Weg:
1. Die ZIP auf einen Webspace/Host mit HTTPS hochladen.
2. index.html öffnen.
3. Im Android-Browser "Zum Startbildschirm hinzufügen" bzw. "App installieren" auswählen.
4. Danach FamilyXP über das App-Symbol starten.

Demo:
Eltern: parent@example.com / 1234
Kinder: max123 / 1234 oder lena123 / 1234

Die Demo speichert Daten lokal im Browser/App-Speicher. Für echte Nutzung auf mehreren Handys brauchen wir anschließend eine sichere Cloud-Datenbank und echte Authentifizierung.
